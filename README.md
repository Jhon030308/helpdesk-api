# 🎫 Helpdesk API

API RESTful desenvolvida em Java com Spring Boot para gerenciamento e suporte de chamados técnicos (Helpdesk).

## 🚀 Tecnologias Utilizadas

* Java 25
* Spring Boot 4 (Spring Web, Spring Data JPA, Validation)
* PostgreSQL (Banco de dados relacional)
* Maven (Gerenciador de dependências)

## 🛠️ Funcionalidades

- [x] Cadastro de chamados técnicos
- [x] Listagem de chamados cadastrados
- [x] Persistência automática no banco PostgreSQL
- [x] Preenchimento automático de datas de criação e atualização

## 💻 Como Executar o Projeto

### Pré-requisitos
- Java 21 ou superior instalado
- PostgreSQL rodando localmente (porta `5432` com banco `helpdesk` criado)
- Maven instalado (ou use o wrapper `./mvnw`)
